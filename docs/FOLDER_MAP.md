# 資料夾路標（與系統示意對齊）

| 路徑 | 用途 |
|---|---|
| `AGENTS.md` | 共用規則 |
| `CLAUDE.md` | vendor 薄相容，指向 AGENTS |
| `.agents/skills/` | 可重用程序 |
| `docs/GOAL.md` | 願景 |
| `docs/BLUEPRINT.md` | 全域規格 |
| `docs/plans/` | Plan／Tasks／驗收 |
| `docs/DEVELOP_LOG.md` | 時間線與證據索引 |
| `docs/DEBUG_LIST.md` | 待處理 |
| `src/` | 產品程式 |
| `tests/` | 測試 |
| `scripts/` | 固定腳本 |
| `.github/` | Issue 模板與 CI |
| `proposals/` | 雙方提案原文（流程考題用） |

小專案可合併文件；重點是責任清楚。程式樹依產品架構，不強制照 Goal／Plan／Task 建資料夾名。
