# Jules 逾時介入

系統流程補丁（使用者要求）：**Jules 執行時間過長，協調者必須介入觀察。**

詳見協調者 SoT `FLOW.md` 與 Skill [jules-t-15-check] / [vibe-coding-system-goal]。

## 門檻（小白話）
| 情況 | 要做什麼 |
|---|---|
| 派工後 15–20 分 | 抽查還在不在動 |
| 約 25 分沒進度 | 必須介入解卡 |
| 同一步驟約 40 分（如裝套件） | 必須介入；可開新 Session |
| 你說卡住 | 立刻介入 |

介入：看卡在哪 → 下令解卡 → 必要時新 Session → 寫進 Issue。不用你去點 Jules 監工。
