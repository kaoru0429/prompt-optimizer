# 提示詞優化器（prompt-optimizer）

把**簡單需求**擴成**通用提示詞**或**提示詞鏈**。第一版：繁中對話介面；先用規則／模板擴寫（不強制外部模型 API）。

- 入口說明：你只跟 Grok Bot 討論需求與驗收；開發走四家平台流程（見 `AGENTS.md`）。
- 文件：`docs/GOAL.md`、`docs/BLUEPRINT.md`、`docs/plans/`。

## 第一版共識（已對齊）
1. 對話式介面  
2. 繁體中文  
3. 可輸出「一則完整提示詞」或「分步驟提示詞鏈」  
4. 先用規則／模板擴寫  
5. 本 Repo 亦作為多平台開發流程之考題專案  

## 開發與執行
- **測試**：執行 `npm test` 或 `node --test tests/` 即可執行所有單元測試。
- **本地執行**：此為純前端靜態專案，無須編譯。請直接用瀏覽器開啟 `index.html`，或使用任何靜態伺服器（例如 `npx serve .`）來開啟。
- **部署**：將專案推送到 GitHub 後，只需將 GitHub Pages 設定指向 repository root 即可完成部署。
